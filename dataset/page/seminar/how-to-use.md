# How to Use - Seminar Page Kalivergo

## 1. Overview Seminar Page
Halaman Seminar adalah hub untuk semua aktivitas terkait seminar, webinar, dan event akademik di Kalivergo. Fitur utama:
- Browse upcoming seminars
- Registrasi event
- Akses recording seminar sebelumnya
- Certificate management
- Calendar integration

## 2. Komponen Utama

### 2.1 Filter & Search
- **Search Bar**: Cari berdasarkan judul, pembicara, atau topik
- **Category Filter**: Filter by kategori (Teknologi, Bisnis, Sains, dll)
- **Date Range**: Pilih rentang tanggal
- **Status Filter**: Upcoming, Live, Recorded, My Registrations
- **Sort Options**: Date, Popularity, Duration, Rating

### 2.2 Featured Seminars
- Highlighted events di bagian atas
- Editor's picks
- Trending seminars
- Special announcements

### 2.3 Seminar Cards
Setiap card menampilkan:
- **Thumbnail**: Visual representation
- **Title**: Judul seminar
- **Speaker**: Nama dan credentials pembicara
- **Date & Time**: Jadwal pelaksanaan
- **Duration**: Estimasi durasi
- **Capacity**: Slot tersedia (untuk limited seats)
- **Tags**: Kategori dan level difficulty
- **Action Button**: Register / Watch / Details

### 2.4 Calendar View
- Monthly calendar dengan marker event
- Click date untuk lihat events hari itu
- Add to personal calendar (Google, Outlook, iCal)
- Reminder settings

### 2.5 My Seminars Section
- **Registered**: Event yang sudah didaftarkan
- **Attended**: Event yang sudah dihadiri
- **Certificates**: Sertifikat yang diperoleh
- **Watchlist**: Event yang disimpan untuk nanti

### 2.6 Speaker Profiles
- Bio dan credentials
- Other upcoming seminars
- Past recordings
- Contact/Social links (jika available)

## 3. Cara Menggunakan

### 3.1 Mencari Seminar
1. Gunakan search bar untuk keyword spesifik
2. Apply filters untuk narrow down results
3. Sort by relevance atau date
4. Preview details sebelum register

### 3.2 Registrasi Seminar
1. Klik seminar card untuk detail lengkap
2. Review requirements dan prerequisites
3. Click **Register** button
4. Confirm registration
5. Receive confirmation email
6. Add to calendar (optional)

### 3.3 Mengikuti Seminar Live
1. Login 10 menit sebelum start time
2. Go to "My Seminars" > "Registered"
3. Click **Join** button saat event dimulai
4. Participate via chat/Q&A feature
5. Complete attendance verification

### 3.4 Mengakses Recording
1. Go to "Recorded" tab
2. Search atau browse catalog
3. Click **Watch** untuk mulai
4. Playback controls: speed, quality, captions
5. Bookmark timestamps untuk referensi

### 3.5 Mendapatkan Sertifikat
1. Attend full session (atau watch full recording)
2. Complete post-seminar quiz (jika ada)
3. Submit feedback form
4. Certificate akan generate otomatis
5. Download dari "My Certificates" section

## 5. Tips & Best Practices

### 5.1 Sebelum Seminar
- Register early untuk secure spot
- Check technical requirements
- Test audio/video beforehand
- Prepare questions in advance
- Read pre-seminar materials

### 5.2 Selama Seminar
- Join early untuk avoid technical issues
- Mute microphone when not speaking
- Use chat untuk questions
- Take notes (built-in note feature available)
- Complete attendance check-ins

### 5.3 Setelah Seminar
- Review recording untuk reinforce learning
- Complete feedback form
- Download certificate
- Apply learnings dalam practice
- Share insights dengan network

### 5.4 Building Portfolio
- Track all attended seminars
- Organize certificates by category
- Showcase in professional profile
- Continuous learning streaks

## 6. Troubleshooting

### 6.1 Technical Issues
- **Can't join live stream**: Check internet connection, refresh page
- **Audio/Video problems**: Check browser permissions, try different browser
- **Chat not working**: Clear cache, disable ad blockers
- **Recording won't play**: Check format compatibility, update browser

### 6.2 Registration Issues
- **Event full**: Join waitlist, get notified if spots open
- **Can't find registration**: Check if already registered in "My Seminars"
- **Payment issues** (for paid events): Contact support

### 6.3 Certificate Issues
- **Certificate not generated**: Ensure 100% attendance and completed quiz
- **Wrong name on certificate**: Update profile before generating
- **Can't download**: Try different browser or contact support

## 7. Keyboard Shortcuts
- `S`: Open search
- `C`: Go to calendar view
- `M`: My Seminars
- `R`: Filter by recorded
- `U`: Filter by upcoming
- `?`: Show shortcuts help

**Q: Apakah seminar gratis?**
A: Sebagian besar seminar gratis, beberapa premium seminar mungkin berbayar.

**Q: Berapa lama sertifikat diproses?**
A: Sertifikat tersedia immediately setelah memenuhi requirements.

**Q: Bisa akses recording berapa lama?**
A: Recording tersedia selamanya untuk registered participants.

**Q: Apakah ada batas jumlah registrasi?**
A: Tidak ada batas, tapi manage waktu dengan bijak.
