# How to Use - CMS Information (Kelola Informasi Kelas)

> Berlaku untuk versi Kalivergo saat ini.

## 1. Apa itu CMS Information

`/{slug}/cms/information` adalah halaman untuk pengurus kelas mengelola postingan informasi dan pengumuman. Postingan yang dibuat di sini akan muncul di feed informasi anggota (`/{slug}/information`).

## 2. Fitur Utama

### 2.1 Buat Postingan Baru

- **Judul**: judul postingan.
- **Konten**: isi postingan.
- **Tipe Postingan**:
  - **TEXT**: teks saja.
  - **IMAGE**: gambar.
  - **VIDEO**: video.
  - **PDF**: dokumen PDF.
- **Upload File**: unggah file media (opsional, sesuai tipe postingan).

### 2.2 Daftar Postingan

- Menampilkan semua postingan yang sudah dibuat.
- Setiap postingan menampilkan: judul, tipe, konten, pembuat, waktu pembuatan, jumlah pembaca, komentar, dan reaksi.
- Postingan dapat dihapus.

### 2.3 Metrik Postingan

- **Read Marks**: jumlah dan daftar anggota yang sudah membaca postingan.
- **Comments**: jumlah komentar.
- **Reactions**: jumlah reaksi (LIKE, LOVE, LAUGH, WOW, SAD, ANGRY).

## 3. Hak Akses

- OWNER memiliki akses penuh.
- Role CMS lain memerlukan permission module **information** untuk mengakses halaman ini.

## 4. Cara Menggunakan

1. Login sebagai pengurus/owner dengan akses information.
2. Buka `/{slug}/cms/information`.
3. Pilih tipe postingan dan isi konten.
4. Unggah file jika diperlukan.
5. Klik **Buat Postingan**.
6. Pantau metrik (pembaca, komentar, reaksi) untuk melihat tingkat keterbacaan.

## 5. Tips

- Gunakan tipe yang sesuai dengan konten agar tampil optimal di feed anggota.
- Periksa jumlah pembaca untuk mengetahui berapa anggota yang sudah melihat pengumuman.
