# How to Use - CMS Audit (Log Aktivitas)

> Berlaku untuk versi Kalivergo saat ini.

## 1. Apa itu CMS Audit

`/{slug}/cms/audit` adalah halaman untuk memantau semua perubahan dan aktivitas yang terjadi di dalam kelas. Halaman ini mencatat siapa yang melakukan apa, kapan, dan di module apa.

## 2. Fitur Utama

### 2.1 Filter Audit Log

- **Module**: filter berdasarkan modul (Semua, Finance, Tasks, People Management, Schedule, Seminar, Access Control).
- **Tanggal Mulai & Tanggal Akhir**: filter berdasarkan rentang tanggal.
- **Ekspor PDF**: unduh laporan audit dalam format PDF.

### 2.2 Tabel Audit Log

- Menampilkan riwayat aktivitas: waktu, pengguna, module, aksi, dan detail perubahan.
- Berguna untuk investigasi jika ada data yang berubah secara tidak diharapkan.

## 3. Cara Menggunakan

1. Login sebagai pengurus/owner.
2. Buka `/{slug}/cms/audit`.
3. Pilih module dan rentang tanggal yang ingin dilihat.
4. Klik **Filter** untuk menerapkan.
5. Klik **Ekspor PDF** untuk mengunduh laporan.

## 4. Tips

- Periksa audit secara rutin, terutama setelah ada perubahan penting.
- Gunakan filter module untuk mempercepat pencarian.
- Cocokkan waktu, pengguna, dan module saat menyelidiki masalah data.
