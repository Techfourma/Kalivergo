# How to Use - Statistics (Statistik Progres Tugas)

> Berlaku untuk versi Kalivergo saat ini.

## 1. Apa itu Halaman Statistics

`/{slug}/statistics` menampilkan statistik progres pengerjaan tugas kelas. Halaman ini membantu pengurus/anggota melihat sejauh mana tugas dikerjakan oleh tiap anggota.

## 2. Komponen Utama

### 2.1 Filter

- **Pilih anggota**: tampilkan statistik untuk semua anggota atau satu anggota tertentu.
- **Rentang tanggal**: filter tugas berdasarkan `startDate` dan `deadline`.

### 2.2 TaskProgressChart

- Grafik ringkasan progres: jumlah tugas diserahkan (`submitted`) vs menunggu (`pending`) dan tingkat penyelesaian.

### 2.3 TaskProgressDetail

- Rincian progres per tugas, termasuk per **pertemuan**.
- Untuk satu anggota, menampilkan per tugas: total pertemuan, pertemuan selesai, dan persentase.
- Untuk semua anggota, menampilkan ringkasan agregat.

## 3. Cara Menggunakan

1. Login ke kelas, buka `/{slug}/statistics`.
2. Pilih anggota atau biarkan "Semua Anggota".
3. Atur rentang tanggal bila perlu, lalu periksa grafik dan detail.
4. Gunakan tombol reset untuk kembali ke rentang default.

## 4. Tips

- Data bersumber dari submission tugas; pastikan submission sudah benar di CMS tasks agar statistik akurat.
