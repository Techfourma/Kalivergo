# How to Use - Profil Page Kalivergo

## 1. Overview Profil Page
Halaman Profil adalah pusat manajemen identitas dan preferensi akun Anda di Kalivergo. Fitur utama:
- Personal information management
- Academic credentials
- Privacy & security settings
- Notification preferences
- Learning preferences

## 2. Komponen Utama

### 2.1 Profile Header
- **Profile Picture**: Upload/change foto profil
- **Name Display**: Nama lengkap yang ditampilkan
- **Badge/Level**: Achievement badges dan level pengguna
- **Edit Button**: Quick access ke edit mode

### 2.2 Personal Information Section
- **Full Name**: Nama sesuai identitas
- **Email**: Email utama (untuk login dan notifikasi)
- **Phone Number**: Nomor telepon (optional, untuk 2FA)
- **Date of Birth**: Untuk age verification dan personalization
- **Gender**: Optional demographic data
- **Nationality**: Untuk regional customization

### 2.3 Academic Information
- **Institution**: Nama universitas/sekolah
- **Faculty/Department**: Fakultas dan jurusan
- **Study Level**: S1, S2, S3, atau lainnya
- **Student ID**: NIM/NPM (optional)
- **Graduation Year**: Tahun estimasi kelulusan
- **Field of Study**: Bidang studi/minat utama

### 2.4 Skills & Interests
- **Skills**: Daftar kompetensi yang dimiliki
- **Interests**: Topik yang diminati untuk rekomendasi konten
- **Learning Goals**: Target pembelajaran pribadi
- **Expertise Level**: Self-assessment per topik

### 2.5 Privacy Settings
- **Profile Visibility**: Public/Private/Friends only
- **Data Sharing**: Opt-in/out untuk analytics
- **Activity Display**: Show/hide activity dari profile
- **Search Indexing**: Allow/disallow profile search

### 2.6 Security Settings
- **Change Password**: Update password
- **Two-Factor Authentication**: Enable/disable 2FA
- **Login Sessions**: View dan manage active sessions
- **Connected Accounts**: Google, Microsoft, etc.

### 2.7 Notification Preferences
- **Email Notifications**:
  - Seminar reminders
  - Weekly summaries
  - Platform updates
  - Marketing communications
- **Push Notifications**:
  - Live seminar alerts
  - Task deadlines
  - New recommendations
- **In-App Notifications**:
  - Messages
  - Achievements
  - System announcements

### 2.8 Learning Preferences
- **Language**: Bahasa interface dan konten
- **Content Format**: Video, text, interactive preference
- **Difficulty Level**: Default difficulty untuk rekomendasi
- **Time Availability**: Estimated learning time per day/week
- **Learning Style**: Visual, auditory, kinesthetic preferences

### 2.9 Account Statistics
- **Member Since**: Tanggal bergabung
- **Total Learning Hours**: Kumulatif jam belajar
- **Seminars Attended**: Total seminar dihadiri
- **Certificates Earned**: Jumlah sertifikat
- **AI Interactions**: Total interaksi dengan AI Assistant

### 2.10 Danger Zone
- **Download Data**: Export semua data pribadi
- **Deactivate Account**: Temporary disable akun
- **Delete Account**: Permanent deletion (irreversible)

## 3. Cara Menggunakan

### 3.1 Edit Profil
1. Click **Edit Profile** button
2. Update informasi yang ingin diubah
3. Upload new profile picture (max 5MB, JPG/PNG)
4. Click **Save Changes**
5. Review changes sebelum confirm

### 3.2 Verifikasi Email
1. Go to Security Settings
2. Click **Verify Email**
3. Check inbox untuk verification link
4. Click link dalam email
5. Status akan update otomatis

### 3.3 Mengaktifkan 2FA
1. Go to Security Settings
2. Click **Enable Two-Factor Authentication**
3. Scan QR code dengan authenticator app
4. Enter verification code
5. Save backup codes securely

### 3.4 Mengatur Notifikasi
1. Go to Notification Preferences
2. Toggle on/off sesuai preference
3. Set frequency (instant, daily digest, weekly)
4. Test notification settings
5. Save preferences

### 3.5 Mengubah Password
1. Go to Security Settings
2. Click **Change Password**
3. Enter current password
4. Enter new password (min 8 chars, mix of letters, numbers, symbols)
5. Confirm new password
6. Click **Update Password**

### 3.6 Managing Connected Accounts
1. Go to Security Settings > Connected Accounts
2. Click **Connect** untuk add new account
3. Authorize melalui provider
4. Click **Disconnect** untuk remove connection
5. Note: Cannot disconnect if it's your only login method

## 4. Tips & Best Practices

### 4.1 Profile Optimization
- Use professional photo untuk profile picture
- Complete all academic information untuk better recommendations
- Regularly update skills dan interests
- Keep contact information current

### 4.2 Security Best Practices
- Use strong, unique password
- Enable 2FA untuk extra security
- Review active sessions regularly
- Don't share account credentials

### 4.3 Privacy Management
- Review privacy settings periodically
- Be mindful of what information is public
- Adjust settings based on comfort level
- Understand data usage policies

### 4.4 Notification Management
- Customize notifications to avoid overload
- Use email digest untuk non-urgent updates
- Enable critical notifications (deadlines, live events)
- Periodically review and adjust

### 4.5 Data Portability
- Download data backup secara berkala
- Export certificates untuk portfolio
- Keep records of achievements
- Review data before deleting account

## 5. Troubleshooting

### 5.1 Profile Issues
- **Can't upload photo**: Check file size and format
- **Changes not saving**: Clear cache, try different browser
- **Information won't update**: Ensure all required fields filled
- **Profile picture not showing**: Refresh page, check privacy settings

### 5.2 Login & Security
- **Forgot password**: Use "Reset Password" feature
- **2FA not working**: Check time sync on device, use backup codes
- **Account locked**: Contact support dengan verification
- **Suspicious activity**: Change password immediately, review sessions

### 5.3 Notification Issues
- **Not receiving emails**: Check spam folder, verify email address
- **Too many notifications**: Adjust frequency settings
- **Push notifications not working**: Check browser/device permissions
- **Missing important alerts**: Whitelist kalivergo.com domain

### 5.4 Account Recovery
- Lost access to email: Contact support dengan alternative verification
- Deleted account accidentally: Contact support within 30 days
- Hacked account: Report immediately, secure connected accounts

## 6. Data & Privacy FAQ

**Q: Bagaimana data saya digunakan?**
A: Data digunakan untuk personalisasi pengalaman belajar dan improvement layanan. Lihat Privacy Policy untuk detail.

**Q: Bisakah saya menghapus data saya?**
A: Ya, Anda dapat download data dan request deletion melalui Danger Zone.

**Q: Apakah profil saya visible oleh publik?**
A: Tergantung privacy settings Anda. Default adalah private.

**Q: Berapa lama data disimpan?**
A: Data disimpan selama akun aktif. Setelah deletion, data dihapus dalam 30 hari.
