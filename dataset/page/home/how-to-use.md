# How to Use - Home Page Kalivergo

## 1. Overview Halaman Home
Halaman home adalah pintu masuk utama ke platform Kalivergo. Halaman ini memberikan:
- Gambaran umum tentang fitur platform
- Akses cepat ke fitur utama
- Personalisasi berdasarkan aktivitas pengguna
- Update dan pengumuman terbaru

## 2. Komponen Utama

### 2.1 Header
- **Logo Kalivergo**: Klik untuk kembali ke home
- **Search Bar**: Cari konten, seminar, atau dokumen
- **Notification Bell**: Lihat notifikasi terbaru
- **Profile Menu**: Akses pengaturan akun dan logout

### 2.2 Hero Section
- **Welcome Message**: Salam personalisasi untuk pengguna
- **Quick Actions**: Tombol akses cepat ke fitur populer
  - "Mulai Belajar"
  - "Lihat Dashboard"
  - "Jadwalkan Seminar"

### 2.3 Feature Cards
Tiga kartu fitur utama:
1. **AI Assistant**
   - Chat dengan asisten akademik AI
   - Dapatkan bantuan belajar 24/7
   - Klik untuk membuka chat interface

2. **Dashboard**
   - Track progress pembelajaran
   - Lihat statistik dan analytics
   - Akses riwayat aktivitas

3. **Seminar**
   - Browse jadwal seminar upcoming
   - Registrasi event
   - Akses recording seminar sebelumnya

### 2.4 Recent Activity
- Menampilkan aktivitas terakhir pengguna
- Quick resume untuk melanjutkan sesi sebelumnya
- History pencarian dan interaksi

### 2.5 Recommended Content
- Konten yang dipersonalisasi berdasarkan:
  - Riwayat pembelajaran
  - Topik yang diminati
  - Trending content di platform

### 2.6 Footer
- Link ke Privacy Policy
- Link ke Terms of Service
- Contact information
- Social media links

## 3. Cara Menggunakan

### 3.1 Untuk Pengguna Baru
1. **Sign Up/Login**: Klik tombol di pojok kanan atas
2. **Complete Profile**: Isi informasi akademik Anda
3. **Explore Features**: Gunakan quick actions untuk mencoba fitur
4. **Set Preferences**: Atur minat dan preferensi pembelajaran

### 3.2 Untuk Pengguna Existing
1. **Check Notifications**: Lihat update sejak kunjungan terakhir
2. **Continue Learning**: Lanjutkan dari recent activity
3. **Explore New Features**: Cek fitur baru yang ditambahkan

## 4. Tips & Best Practices

### 4.1 Maximizing Home Page
- Gunakan search bar untuk navigasi cepat
- Bookmark halaman yang sering diakses
- Enable notifications untuk update penting

### 4.2 Personalization
- Update preferensi secara berkala
- Interaksi dengan konten akan meningkatkan rekomendasi
- Feedback pada rekomendasi membantu improve algoritma

## 5. Troubleshooting

### 5.1 Masalah Umum
- **Loading lambat**: Refresh halaman atau clear cache
- **Konten tidak muncul**: Check koneksi internet
- **Personalization tidak akurat**: Update preferences di profil

### 5.2 Dukungan
- FAQ section tersedia di footer
- Live chat support (jam kerja)
- Email support: support@kalivergo.com

## 6. Keyboard Shortcuts
- `Ctrl + K`: Buka search
- `Ctrl + /`: Buka shortcut menu
- `Esc`: Tutup modal/dialog
